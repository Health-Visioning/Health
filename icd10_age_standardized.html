Switch between raw counts and age-standardized rates (per 100,000, standardized to the 2019 population) using the toggle below — the row set, hierarchy, and z-score method stay the same, only the displayed numbers and flags change to match. Sub-groups and specific-code rows whose 2022 raw count fell under 100 have been removed (chapters are always kept regardless of size), cutting the table from 1,284 rows to 306 — this applies to both views, so toggling never changes which rows are shown. Neoplasms is restricted to malignant cancers only (C00–C97).

Methodology

For each row, a linear trend is fit through 2000–2019 and extrapolated to 2022 as the expected value. The "2020–24 avg" column's z-score compares the actual 2020–2024 average to that expectation, using the larger of two noise estimates (empirical 5-year rolling-window spread, or a regression-theory floor) to avoid an artificially small denominator. Both views use this identical method — the counts view scores raw annual death counts, the rate view scores age-standardized rates, so any difference between the two for a given row directly reflects how much of that row's signal was driven by Canada's population growth and aging versus a genuine shift in risk.
